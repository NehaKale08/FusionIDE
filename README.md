# 🚀 FusionIDE

FusionIDE is an AI-powered collaborative Integrated Development Environment (IDE) inspired by Visual Studio Code.

This project was developed as a Final Year BE Computer Engineering project.

---

## ✨ Features

- 🤖 Google Gemini AI Chatbot
- 🎤 Voice-to-Code
- 💻 VS Code Inspired UI
- 📂 File Explorer
- 📝 Multi-file Code Editor
- 👥 Real-time Collaboration (Room Based)
- 📊 UML Diagram Generator
- 🌙 Dark Theme
- ⚡ Syntax Highlighting
- 🔍 Code Explanation
- 📋 Copy Code
- 💬 AI Programming Assistant

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/NehaKale08/FusionIDE.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm start
```
